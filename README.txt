# Nepalan Birthday Card 🎀

## Files
- `index.html` — the birthday card
- `style.css` — design and animations
- `script.js` — interactions, photos, cake and music
- `photo1.jpg` ... `photo5.jpg` — your photos
- `tu-chahiye.mp3` — your music

## Run on your PC
Double-click `index.html`.

If your browser blocks local audio, open the page through a simple local server or use GitHub Pages.

## GitHub Pages
1. Create a GitHub repository.
2. Upload every file in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The first **Open your birthday surprise 🎀** click starts the music because modern browsers generally block audio autoplay until the visitor interacts with the page.


## If music does not start
The music starts from the first click on the "Open your birthday surprise" button. If Chrome blocks it on a local file, use the GitHub Pages link after publishing; the audio is an MP3 and will work there after the opening click.
